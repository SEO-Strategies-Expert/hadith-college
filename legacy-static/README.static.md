# كلية الحديث وعلومه

نسخة العرض الأولية لموقع **كلية الحديث وعلومه** والمنصة التعليمية البحثية، جاهزة للنشر كموقع ثابت على Vercel.

## المحتوى

- الموقع العام وصفحاته الأكاديمية والبحثية.
- مختبر التخريج ودراسة الأسانيد.
- مختبر التحقيق وعلوم المخطوطات.
- المكتبة الرقمية والمواقع الحديثية البحثية.
- القبول ونظام الرسوم المرن.
- لوحات الطالب، مدير الكلية، وهيئة التدريس.
- تصوّر تقويم البث المباشر وروابط Zoom والتنبيهات البريدية.

## التشغيل محليًا

يمكن فتح `index.html` مباشرة، أو تشغيل خادم محلي بسيط:

```bash
python -m http.server 8000
```

ثم زيارة `http://localhost:8000`.

## النشر على Vercel

المشروع Static HTML ولا يحتاج إلى أمر Build. عند استيراد المستودع إلى Vercel:

- Framework Preset: **Other**
- Build Command: اتركه فارغًا
- Output Directory: اتركه فارغًا
- Root Directory: جذر المستودع

## ملاحظة تقنية

وظائف Zoom، البريد، تسجيل الدخول، الحفظ المركزي، وإدارة قواعد البيانات معروضة حاليًا كنماذج Front-end، وتحتاج Backend وواجهات API في مرحلة التطوير البرمجي النهائية.
