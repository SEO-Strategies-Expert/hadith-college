# دليل هيئة التدريس

افتح `/dashboard/faculty/courses`.

يرى المدرس الشعب المسندة إليه فقط. إذا لم تظهر شعبة، يجب على الإدارة تعيينه من `/dashboard/admin/academic/sections`.

داخل صفحة الشعبة:

- أنشئ وحدة.
- احفظها كمسودة أو انشرها.
- أنشئ درسًا داخل الوحدة.
- أضف نصًا أو روابط فيديو/صوت/PDF أو مراجع.
- انشر الدرس ليظهر للطلاب المسجلين.

لا يمكن للمدرس إدارة برنامج أكاديمي أو شعبة غير مسندة إليه؛ يتم التحقق في Server Actions وRLS.
