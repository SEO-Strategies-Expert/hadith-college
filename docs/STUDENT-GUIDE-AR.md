# دليل الطالب

افتح `/dashboard/student`.

تعرض اللوحة:

- اسم الطالب.
- البرنامج والمستوى.
- المقررات المسجل بها.
- Placeholder منظم للمحاضرات القادمة.

افتح `/dashboard/student/courses` لعرض المقررات، ثم افتح المقرر والدرس.

داخل الدرس:

- اقرأ المحتوى أو افتح الموارد.
- احفظ نسبة التقدم.
- عند 100% يتم تسجيل `completed_at` و`is_completed`.

لا يرى الطالب مقررات أو دروس شعب غير مسجل بها.
