# رفع المشروع إلى GitHub ثم Vercel

المستودع المقترح: `SEO-Strategies-Expert/html-starter`

## GitHub Web

1. افتح المستودع.
2. احذف ملفات القالب القديمة: `index.html` و`middleware.js` و`package.json` و`README.md`.
3. اختر **Add file → Upload files**.
4. ارفع جميع محتويات هذا المجلد مع الحفاظ على المجلدات `assets` و`dashboards`.
5. اكتب رسالة Commit مثل: `Deploy Hadith College website preview` ثم اضغط Commit changes.

## Vercel

1. اختر **Add New → Project**.
2. استورد المستودع `html-starter`.
3. Framework Preset: **Other**.
4. اترك Build Command وOutput Directory فارغين.
5. اضغط Deploy.
